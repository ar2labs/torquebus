# TorqueBus Studio 0.17.0 Preview 1

This candidate packages the current 0.17.0 development build as a Windows 11
x64 Preview. The executable reports its milestone version (`0.17.0`); the
`preview.1` suffix identifies this candidate package.

## What to try

- Open the included `examples/projects/j1939-vehicle.tbsproj` and run the
  simulated truck on the built-in virtual CAN channels.
- Watch live vehicle speed, engine speed, coolant temperature, fuel, DEF,
  voltage, oil pressure, and the TinyML telemetry in the Dashboard.
- Inspect decoded J1939 and UDS traffic in CAN Trace; explore ECUs, address
  claims, and diagnostic faults in J1939 Network and Active faults.
- Try editing the example pipeline, Lua ECUs, DBC, and dashboard configuration.

## Package

`TorqueBus-Studio-v0.17.0-preview.1-win64.zip` contains the application, Qt
runtime/QML dependencies, optional J2534 and PEAK plugins, license and
changelog, and the runnable virtual CAN examples. It does not include vendor
drivers, PCAN-Basic, a Kvaser SDK, or the licensed J1939 manufacturer table.

See [`../PREVIEW.md`](../PREVIEW.md) for first-run steps and hardware notes.

- The tagged release workflow builds and runs the automated suite, checks
